### What this means in simple terms

**This test asks: does the knowledge graph actually help?** The same 15 questions went to two versions of Navi. **Baseline** can only search the documents, and **GraphRAG** can also use the graph. Scores are out of 2, so 1.40 means 70%.

| Question type | Baseline correct | GraphRAG correct | What it means |
|---|---|---|---|
| Lookup ("What is the CAC fee?") | 90% | 80% | No real difference. One fact sits in one paragraph, and both versions find it the same way |
| Multi-step ("What do I need, and in what order?") | 40% | **70%** | The graph clearly helps, because the answer depends on links across several documents |
| Progress ("I've done X, what's left?") | 40% | **70%** | The graph clearly helps, because it knows every step and which are done |

**GraphRAG also did less work:** 5 document searches against 34 for the baseline, and about 18% fewer input tokens per reply.

**Three things to know when reading the table above:**

- **The lookup gap is a judge mistake.** The judge called the data protection impact assessment "invented" on question L4, but the reviewed graph requires that step for an online cosmetics store.
- **Don't rely on the "Order OK" column.** It's the judge's opinion, and the judge has been wrong about order before. A separate check by code found GraphRAG in a valid order 5/5 on both multi-step and progress questions, against 3/5 and 4/5 for the baseline. That check only sees steps written with their exact names, and baseline replies name fewer steps.
- **GraphRAG's multi-step citations (80%) came out below the baseline's (90%).** Its source lines name the document but not the section, so the judge can mark them either way. The same format scored 100% on 3 November.

**Why GraphRAG isn't higher than 70%:** Navi shortens long checklists when it writes the reply, so some steps get left out. The graph itself supplies every step.

**How far to trust these numbers:** each row is only 5 questions, so one answer moves a score by 10 to 20 points. Treat them as a direction, not an exact measurement.
